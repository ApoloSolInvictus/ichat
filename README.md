# iChat

iChat is a browser-based voice translator. Speech recognition runs in the browser, translation runs on the Vercel serverless API through OpenAI Responses API, and translated audio is generated by ElevenLabs when available.

## Production environment variables

Set these variables in Vercel. Never place provider secrets in `index.html` or commit them to Git:

| Variable | Required | Purpose |
| --- | --- | --- |
| `OPENAI_API_KEY` | Yes | Primary OpenAI key |
| `OPENAI_API_KEY_2` | Recommended | Fallback OpenAI key for transient failure/rate limits |
| `OPENAI_MODEL` | No | Defaults to `gpt-4o-mini`; pin a model available to your account |
| `ELEVENLABS_API_KEY` | No | Premium translated voice; browser speech is used if unavailable |
| `ELEVENLABS_VOICE_ID` | No | ElevenLabs voice; defaults to Rachel's legacy voice ID |
| `ELEVENLABS_MODEL_ID` | No | Defaults to `eleven_multilingual_v2` |
| `ELEVENLABS_OUTPUT_FORMAT` | No | Defaults to `mp3_44100_128` |
| `PAYPAL_CLIENT_ID` | Yes for payments | PayPal client ID |
| `PAYPAL_SECRET` | Yes for payments | PayPal server secret |
| `PAYPAL_ENVIRONMENT` | No | `sandbox` or `live`; defaults to `sandbox` |
| `ACCESS_TOKEN_SECRET` | Strongly recommended | Secret used to sign Pro access tokens |
| `ALLOW_TEST_MODE` | No | Set to `true` only for a private test deployment |

`PAYPAL_SECRET` is used as a temporary signing fallback when `ACCESS_TOKEN_SECRET` is absent, so an existing deployment can migrate without immediately breaking access. Add a dedicated random `ACCESS_TOKEN_SECRET` and remove that fallback dependency as soon as possible.

## Access model

The browser no longer grants Pro access from `localStorage` alone. After PayPal confirms a completed order, the server issues a signed access token bound to the Firebase user ID. The translation API requires that token for Pro requests. The public demo is deliberately limited in length and requests per hour.

## Local checks

```bash
npm test
node --check api/translate.js
node --check api/paypal.js
```

The browser must be served over HTTPS for microphone access. Configure Firebase Authorized Domains and PayPal credentials before enabling production payments.
